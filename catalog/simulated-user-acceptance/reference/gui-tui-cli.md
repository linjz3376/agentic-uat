# GUI / TUI / CLI 三态与拟人入口权威口径

> 立章：拟人强调 GUI 交互操作。本章回答三件事——三态怎么定义、
> persona 真实入口怎么判、三态之间什么关系。与 SKILL.md「场景与真实入口」「拟人操作六纪律」及 tool-selection.md 是**互补不重复**关系：彼处管「怎么操作才留证」，
> 本章管「该用哪个入口才忠实」。

## 1 三态定义（判定时先归类）

| 态 | 定义 | 典型载体 | 驱动原语 |
|---|---|---|---|
| **GUI** | 像素渲染的图形界面，用户经「看屏→指点」完成目标 | 桌面客户端（QQ/微信/Electron）、浏览器页面 | 坐标点击 / DOM 事件 / 剪贴板粘贴 |
| **TUI** | 字符渲染的终端界面，用户经「键盘导航+读屏」完成目标 | 各类 CLI 的交互界面（编辑器/系统监控/AI 编码工具终端形态）、vim、htop | 键盘事件（方向/回车/快捷键）+ 终端读屏（文本快照） |
| **CLI** | 无界面，一次性命令调用，参数进结果出 | git、curl、各类 headless 一次性调用形态、自研 CLI | 进程调用 + 参数/退出码/stdout 契约 |

**归类铁则**：TUI 属 GUI 家族（拟人优先序与 GUI 同级），但其驱动原语是键盘而非鼠标——
把 TUI 当「终端版 GUI」对待，不得当 CLI 对待；CLI 与两者的分界=**有没有「界面会话」**
——有（持续渲染、可交互、有状态呈现）=GUI/TUI 族；无（调用即返回）=CLI。

## 2 persona 真实入口判定（入口忠实的第一刀）

对每个验收动作，先问三问（写入场景日志）：

1. 该 persona 是人、机器还是外部系统？
2. 该动作的业务目标，此 persona 在正常工作中经哪个态达成？
3. 若只能走另外两态，是「该态本就是这个 persona 的合法入口」，还是「降级」？

- 人类 persona 的日常入口 = QQ 客户端窗 / 浏览器 / 桌面 App → **GUI 优先**：
  凡 GUI 可达的能力，不得用 CLI 直调判 PASS（API 直调判 UI 点=测试级别错位，SKILL §2「入口忠实三问」）。
- 人类 persona 中「本职用终端」的开发者角色（如工程师 persona 日常在终端里驱动其 AI 编码工具）：
  TUI 是其真实入口，按 TUI 驱动（键盘+读屏），不因「TUI 长得像 CLI」而降为进程调用。
- 机器/外部系统 persona（回调接收方、定时任务、cron 通知）：CLI/HTTP 就是其**真实入口**，
  按调用方契约验收（SKILL §2「入口忠实三问」），此时「拟人 GUI」不适用——拟人是为人类 persona 立的规。

## 3 GUI ↔ TUI ↔ CLI 的关系矩阵

| 场景 | 正解 | 反例（判失效） |
|---|---|---|
| 同一能力 GUI 与 CLI 都可达，判人类 persona | 走 GUI 全流程，CLI 仅作造数/辅证 | CLI 直调改完再开页面看一眼=UI 写点最高 PARTIAL（SKILL §3「入口分级主证」） |
| TUI 能力与 GUI 能力等价（如 AI 编码工具的 TUI 形态 vs 其桌面 App） | 选该 persona 日常用的那态；两者都属拟人 | 把 TUI 操作退化成该工具的 headless 一次性调用=TUI 点变 CLI 点，入口已换 |
| CLI 是 persona 唯一入口（确无 UI，经入口复核确认） | 按 [MACHINE] 契约验收，不算降级 | 未做入口复核就按 CLI 跑=入口标注违规（SKILL §2「入口忠实三问」） |
| GUI 操作受载体限制（锁屏/无自动化手段） | 有预配真人时降级人工并留痕；无真人则最小作用域 BLOCKED，其他 READY 继续 | 静默退回 API 探测或无触发器空等=违规 |

**互证关系**：GUI/TUI 为主证时，CLI/日志/DB 只能处三个合法位置（SKILL §2「入口忠实三问」：
造数/预声明辅证/机器 persona 契约）；反过来 CLI 为主证时（机器 persona），GUI 侧表现
可作辅证但不得反 CLI 结果推翻。

## 4 拟人强调的落点

- **GUI 交互操作是拟人的默认形态**：真实事件（点击/键入/粘贴/滚动）→ 操作后可观察变化
  → 判定时所见渲染为准 → 留证。四条缺一即该次操作不算完成。
- TUI 拟人=「键盘流拟人」：逐键输入、方向键导航、回车确认，读屏快照判定——
  不是「把命令拼好一次性发给终端」。
- CLI 不进拟人射程：CLI 是契约对象，不是「拟人对象」；把 CLI 当拟人对象
  （如对 CLI 截图判定）= 范畴错误。
