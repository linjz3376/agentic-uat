# 两技能分工界面（skill-interface v1）

> 本文=生成侧（acceptance-contract-governance，下称 ACG）与执行侧（simulated-user-acceptance，下称 SUA）工作范畴的**单源定义**，归治理侧持有；SUA 仅留指针不复制内容——防双源漂移。

## 一、本质分工

| | ACG（立法者） | SUA（执法者+记录者） |
|---|---|
| 使命 | 把「测什么」变成可执行的自包含指令，生产**承诺**（判据/门槛/授权范围/产物清单） | 拿任务书以真实用户身份走旅程，生产**事实**（判定/证据/缺陷） |
| 交付物 | 一份任务书（`<项目>/tests/plans/`，一次性） | 一棵报告树（`<项目>/tests/reports/<date>-<domain>/`，归档级） |
| 生命周期 | 每轮一次，生成即完成不跟执行 | 每轮一次，收官即归档可移交 |
| 模式 | 生成模式（主）+ 治理模式（辅：体检/清污/拆分） | 执行模式（唯一） |

## 二、口径所有权表（一条口径恰好一个 owner）

| 维度 | Owner | 协作界面/规则出处 |
|---|---|
| 覆盖范围（测什么） | **ACG**——四活源：PRD 横切（范围唯一来源）/缺陷台账（仅取修复状态+首现时间+编号，见历史参考白名单）/现行侦察/十一维加钻 | 任务书 §3 主表；SUA 只消费不扩围 |
| 判据（怎么算过） | **ACG 生成**可机判判据 | SUA 执行判定；判据冲突挂起 ⏸️ 递单裁定 |
| 场景模型（八要素/三流/场景-AC 矩阵/handoff） | **ACG 生成** | SUA 场景优先执行；任务书缺流→按用户合理路径补足并记录 |
| 报告三态/产物树/证据与缺陷命名 | **SUA 唯一权威**（artifact-conventions） | ACG 模板内嵌=**生成期快照**，须标执行侧出处（不标版本号）；冲突以执行侧当前版本为准 |
| 覆盖度量三行（需求覆盖/UI 证据/未触率） | **ACG coverage-metrics.md 唯一权威** | SUA 引用不重复定义 |
| 缺陷定义/分类/入库/未触归因四分法 | **SUA §7 唯一权威** | 报告根 defects.md 单文件（含十段式内联） |
| 缺陷台账（状态+编号唯一事实源） | **项目侧自治**（跨轮常驻，`<项目>/tests/reports/defect-ledger.md`） | ACG 生成期读取+头部「缺陷台账快照」行；SUA 开工可达性必核+报告根快照重建 |
| 授权边界 | **SUA §1 常驻条款**+ ACG 模板头部每轮操作化 | 执行域连续执行不设域间确认点；治理域（协议/技能/配置修订、git、目录外、共享数据删除）须用户显式授权 |
| ⛔/⏭️/⏸️ 门槛标记 | ACG 生成时标注并链台账 | SUA 按锚判定；台账=状态单一事实源，任务书/报告只链编号不内嵌状态 |
| 新验收点/新缺陷模式回流 | ACG 下轮吸收（仅缺陷状态/首现时间/编号范围内的回流） | SUA G0/探索产出→**递单回流**；端点/探针/golden 回写 `<项目>/tests/fixtures|playbooks/`（项目侧资产） |

## 三、一轮的接力棒视图

```
人出意图
  → [ACG] 四活源挖素材→场景建模→判据量化→门槛标注→内嵌执行者手册
       ↓ 任务书=承诺（七项数字回执）
  → [SUA] 环境闸 GO（含台账可达性/授权边界确认）→场景优先执行→判定留证
       →缺陷入台账→G0 探索→递单
  → [SUA] 自检 19 项+产物闸（artifact-conventions §4.4 十二项）→三态报告
       →报告根台账快照归档（来源纪律 §4.4-9）
  → [ACG 下轮] 按历史参考白名单读取台账+接收递单 → 生成新版任务书 → 循环
```

铁律：**每一棒的输出=下一棒的输入；任何口径的全局事实源只有一份**。

## 四、默契的三道防漂移机制

1. **一条口径一个 owner**（定义权裁定：执行侧产物口径以执行侧当前版本为准）
2. **跨侧引用=快照+出处标注**——ACG 内嵌执行格式条款标注 SUA 版本；冲突以 SUA 当前版本为准
3. **冲突处置=记偏差+提交裁定，禁止静默执行/静默沿用**——SUA 自检 #16

## 五、人在回路中的授权决策点（其余全部自主）

任务书评审（可选）→ 治理域授权 → ⏸️ 口径冲突裁定 → 报告接收与下轮意图。

## 六、雷区清单（失效模式→在管闸）

| 雷区 | 立闸 |
|---|---|
| 场景表当目录执行 | ACG 场景生成力闸/SUA 执行顺序铁律 |
| 半程收官/双源报告口径 | 快照纪律 + 三态唯一权威 |
| API 200 当契约过 | SUA E2E 原则第 4 条 |
| 执行域幽灵闸（误设域间确认点） | 授权边界条款 |
| 台账活源被删/断链 | 台账来源纪律 + 头部快照行 + 链接闸 |
| 漏挂台账→AC 映射 | ACG G4 台账映射机验 |
| 覆盖度量双源定义 | coverage-metrics.md 单源 |
