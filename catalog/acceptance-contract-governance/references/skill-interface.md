# 两技能分工界面

> 本文是 ACG（生成/治理侧）与 SUA（执行侧）的工作范畴单源。历史 changelog 不属于现行口径。

## 1 本质分工

| | ACG | SUA |
|---|---|---|
| 使命 | 把「测什么」变成风险有界、自包含的任务书，生产承诺 | 以真实入口执行，生产判定、证据、缺陷和报告 |
| 交付物 | 一次性任务书，含冻结执行规范快照 | 报告树与可恢复执行契约 |
| 生命周期 | 生成即完成，不跟执行 | PREFLIGHT 至 CLOSED；接受/回灌另行跟踪 |
| 不得做 | 默认扩张授权、预写执行结论、要求运行时追随当前技能 | 自行降低安全红线、把局部异常默认扩大为全轮停止 |

## 2 口径所有权

| 维度 | Owner | 协作界面 |
|---|---|---|
| 覆盖范围、风险档、判据 | ACG | 产品 AC 仅 UI/MACHINE；DOC 用 AUDIT-ID 独立审计，不进需求验证分子/UAT 三态；历史契约禁作基底 |
| 拟人旅程、预算、停止与执行模式 | SUA | 所有任务书冻结核心；SINGLE_WRITER 默认含共享状态机/逻辑四态/长窗收判/最小断点，PARALLEL_UNATTENDED 仅实际并行/接管时内联租约/CAS/fencing/分片归并 |
| 授权矩阵 | SUA + 项目/全局安全红线 | ACG 生成授权清单；操作者显式确认范围，项目更严规则优先 |
| 场景模型 | ACG | 每关键业务目标有连续基本流/交接/最终结果；禁止域批吞并全部 AC；场景完成与 AC 挂靠分开 |
| 报告三态、保底报告、产物核心约束、命名 | SUA | ACG 固化快照；任务书仅选合法 profile/扩展 |
| 覆盖公式与组合身份 | ACG `coverage-metrics.md` | 任务书内联公式及按需 Cell/Case；SUA 以 Run 主表/Run-Case 明细和当前有效 Run 归格执行，不另定义分子分母，不以场景/复验数替代 Case |
| 缺陷分类与 BLOCKED 六类归因 | SUA | 项目台账持状态；报告签发不等待缺陷修复 |
| 执行契约与写者接管 schema | SUA `artifact-conventions.md` | ACG 内联字段骨架，运行时值由执行者填 |
| 经验回灌 | ACG 下轮吸收合法事实 | 未获项目文档写授权时只留建议，不阻塞 CLOSED |

## 3 静态快照协议

1. 生成时读取 SUA 当前规范，将拟人核心与本轮所选执行模式内联，记录静态出处和哈希；SINGLE_WRITER 必带自主长任务内核，PARALLEL_UNATTENDED 仅实际并行/接管时内联扩展契约。
2. 运行时只读任务书；不得出现「执行期以当前版本为准」。宿主更严安全红线始终从严，其他外部更新不热切换。
3. 外部差异只记录；影响判据真值时相关 AC 实测后 ⏸️，其他 READY 项继续，报告按内嵌规则签发。
4. 产物优先级=SUA 核心约束>任务书合法 profile/扩展>默认布局；任务书不能豁免 UI 主证、安全或报告底线。

## 4 一轮接力

```text
操作者意图与授权范围
  → ACG：源头对账→风险/预算→场景与 AC→按需 Cell/Case→内联冻结规范
  → SUA：按 SINGLE_WRITER/PARALLEL_UNATTENDED 执行真实连续旅程→Run/证据归格→局部受阻续跑
  → 报告首节给关键旅程定性结论→CLOSED（FINAL / FINAL-WITH-GAPS / INTERIM）
  → 独立后续：缺陷修复、风险接受、经验回灌、下轮生成
```

## 5 人在回路中的合法决策点

授权清单确认、判据冲突裁定、风险接受、下轮意图。均可只挂起受影响范围；报告签发与本轮 CLOSED 不以裁定为前置。迟发安全/授权事件不是违规，必须登记并局部处置。

## 6 雷区清单

| 雷区 | 在管约束 |
|---|---|
| 全绿/缺陷修复才停止 | SUA 状态机；CLOSED 与产品闭环分层 |
| 单点受阻全轮等待 | 五级阻塞+四队列+有限预算 |
| 命令即签/默认重启 | 显式授权清单+具名恢复授权 |
| 运行时当前版本指针 | 静态冻结快照 |
| FINAL-WITH-GAPS 被未触=0 误杀 | SUA 三态分别校验 |
| 无 PRD 回退契约基底 | source-reconciliation 四活源降级 |
| 格式缺陷阻止报告 | 保底 INTERIM/直接回复最小报告 |
| DOC/域批/控件清单冒充拟人旅程 | UAT 身份闸+真实连续旅程+AUDIT 独立 |
| 技术信号直接成为 UAT 缺陷 | TECH-OBS 与 persona 入口结果分离 |
| 技能研发治理进入常驻生成 | 仅 maintainer-guide，不参与任务生成 |
| 操作者未签署导致永不收口 | 执行关闭与风险接受分层 |
| 场景/复验数量掩盖组合缺口 | ACG Cell/Case 设计闭格；SUA Run/证据归格，孤儿证据零 credit |
