# 执行控制负样例（应被 §21–§23 拦截）

- 执行模式：EXTENDED_UNATTENDED；因此缺租约、四队列、预算或接管字段均属缺陷。

- 执行期以当前版本为准，运行时才读取外部报告规范。
- 命令即签，沉默=GO，默认授予全集，包括等空闲重启。
- 默认等空闲重启，无需专项确认。
- 全绿或 NO-GO 前不得停。
- 缺陷全部修复才可出报告。
- 单角色凭据失效即全轮停止，独立 AUDIT 项也不执行。
- UNREACHABLE 必须穷尽合法手段并换人/换时间再试。
- 运行中禁止新增人机请求；出现任何迟发依赖即打回生成侧重做。
- 产物命名未过不得出报告，无保底报告。
- 执行契约只有五字段骨架，无写者租约、四队列和预算；回合末三件套。
