# 边界派生规则全表（B 点）

> 配套 `simulated-user-acceptance` §3.2。用途：从字段元模型自动派生边界点，避免「只验主流程」。
> 编号规范：`B-<域>-<序号>`，例 `B-IMP-07`。每个 B 点必须可判定（有输入、有预期、有观察点）。

## 1 派生流程

```
字段元模型（类型/长度/格式/必填/枚举/范围/精度/唯一性/关联）
  → 套用 §2 规则表 → 生成 B 点候选
  → 去重合并（同义边界只留一个）
  → 挂到 AC（每 AC ≥1，负向 AC 必须挂边界）
  → 执行时勾选：通过/失败/阻塞，并记录证据
```

**门槛**：输入字段 ≥5 点；状态字段 ≥3 转换；异步操作 ≥4 时序；文件类 ≥6 格式/大小；分页类 ≥6 组合。

## 2 规则表

### 2.1 手机号 / 编号（11 位数字）

| B 点 | 输入 | 预期 |
|---|---|---|
| 空 | 空串 | 必填提示/0 条 |
| 短 | 1 位 / 10 位 | 格式错误或 0 条 |
| 正常 | 合法 11 位 | 命中 |
| 长 | 12 位 / 20 位 | 格式错误或 0 条 |
| 全角 | `１９９００００９００１` | 拒绝或 0 条 |
| Unicode | `١٩٩٠٠٠٠٩٠٠١`（阿拉伯数字） | 拒绝或 0 条 |
| 前缀 | `+8619900009001` / `86-199...` | 拒绝或按规则解析 |
| 前导零 | `01990000900` | 拒绝或 0 条 |
| 分隔符 | `199-0000-9001` / 含空格 | 拒绝或 0 条 |
| 号段边界 | `19900000000`、`19999999999`、`10000000000` | 存在/不存在符合预期 |
| 注入 | SQLi / XSS / 200 位 | 0 条、无 500、无执行 |
| 唯一性 | 重复导入同号 | 按重复规则处理 |

### 2.2 金额 / 数字

空、0、负数（-0.01）、最小正数（0.01）、上限-1/上限/上限+1、3 位小数（19.999）、非数字（abc）、科学计数（1e10）、NaN/Infinity 字符串、金额显示 2 位小数、导出精度不丢。

### 2.3 日期 / 时间

空、过去、今天、未来、起>止、起=止、跨月、跨年、闰日（2-29）、1970-01-01、时区边界（23:59:59 vs 00:00:00）、导出格式、页面与导出时区一致。

### 2.4 枚举 / 下拉

全部合法值逐个选（至少 5 个；记录选项文案与映射）、非法值（若可构造）、空/默认值、多选组合、选项与列表文案一一对应、无裸码（0/1/2）。

### 2.5 文件上传

| B 点 | 输入 | 预期 |
|---|---|---|
| 0 字节 | 空文件 | 明确提示，不新增 |
| 仅表头 | 无数据行 | 「无有效数据」提示 |
| 合法最小 | 1 行 | 成功 |
| 合法批量 | N 行 | 成功，计数正确 |
| 上限-1/上限/上限+1 | 4500/4501 类 | 与文案一致 |
| 伪装扩展 | txt→xlsx、zip→xls | 拒绝，不落盘 |
| 损坏 | 截断 zip | 解析失败提示 |
| 宏 | .xlsm 伪装 .xls | 拒绝，不执行 |
| 超长文件名 | 255+ 字符 | 不崩溃 |
| 中文/特殊字符文件名 | 号码导入_20261027.xlsx | 正常 |
| 空文件名 | multipart 无 filename | 明确提示 |
| 压缩炸弹 | 高压缩比 zip | 限时/拒绝 |

### 2.6 分页 / 列表

0 条、1 条、满页、最后一页（余数）、超页（回退/空页）、切页大小（回第 1 页）、筛选变化后页码（重置？）、总数变化后当前页越界、排序稳定性（同值次键）、空态文案、loading 态。

### 2.7 数量 / 批次

0、1、上限-1、上限、上限+1、双倍上限、超大批次中断、重试幂等、批次号格式、成功+失败+重复=总数。

### 2.8 状态机

| 点 | 说明 |
|---|---|
| 合法转换 | 每个箭头至少 1 次（如 未分配→已分配→激活→注销） |
| 非法转换 | 终态再操作、跨级跳转、回退 |
| 并发双写 | 两会话同时操作同一对象，仅一个成功 |
| 回滚/超时 | 预占用超时回收、任务超时 |
| 状态联动 | 主状态变化后关联字段（时间/号卡/企业）同步 |

### 2.9 异步 / 任务 / 时序

| 点 | 说明 |
|---|---|
| 提交即刷新 | 页面状态是否丢失/重复 |
| 中断 | 处理中关闭页面/断网，恢复后无半批 |
| 重试 | 同一请求重放，幂等 |
| 重复提交 | 双击/双标签，仅一个有效批次 |
| 乱序完成 | 先提交后完成 vs 后提交先完成 |
| 超时 | 超过阈值有明确失败态与重试入口 |

### 2.10 一致性（字段×位置矩阵）

对证件号、金额、状态、时间、企业名等关键字段，逐格核对：

```
字段 × [列表 | 详情 | 导出 | 关联页 | 消息 | 接口]
```

任一处规则不同（掩码/格式/精度/时区）即缺陷。示例：列表掩码前3后4、导出明文 → 立即记 P1。

### 2.11 安全边界

SQLi/XSS/路径穿越/超长串（查询框与写入字段各一组）、越权 id/企业 id、低权限接口直调、恶意文件、CSRF（有独立 Origin 时）、敏感字段在导出/日志/错误信息中的出现。

### 2.12 性能 / 可观测性

首屏/搜索/翻页 ≤ 阈值（3 次取中位数）、大批量操作耗时、下载耗时、console error、4xx/5xx、慢请求、任务三态。

## 4 与任务书的挂接

1. 任务书生成阶段：对每个字段/状态/异步点跑本表，产出 B 点清单（表格：B-ID / 关联 AC / 输入 / 预期 / 层级 L3）。
2. 主表每个 AC 增加一列「B 点」引用。
3. 执行台账增加 B 点勾选列；报告输出「B 点执行率 = 已执行/派生总数」与「B 点命中缺陷数」。
4. 覆盖率体检：若某 AC 无 B 点、或 B 点 < 门槛，判「边界覆盖不足」并要求补充。
