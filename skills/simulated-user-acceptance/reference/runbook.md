# 执行通道操作规程（方法层 runbook）

> 定位：**方法层**——「选定执行通道后怎么走」（接入→工作流→失效处置→降级链）。
> 姊妹篇分工：`tool-selection.md` 管「驱动器够格吗」（选型判据三问），本文管「够格之后怎么用」。
> 工具面分层：本文只登记**能力类别+代表名**（代表≠背书，用时以官方仓库验证）；**当期工具面盘点归项目侧 playbook**（各节末指针）——技能记类目与门牌号，项目记当下住户名单。
> 可移植性铁律：零实例残留（无机器/IP/凭据/路径）；项目专属接线一律不写本文。

## 通道×OS 覆盖矩阵

| 通道＼OS | Windows | macOS | Linux | 验证状态口径 |
|---|---|---|---|---|
| 浏览器（DOM/a11y 快照） | ✅ | ✅ | ✅ | 多项目已验证（结构层首选通道） |
| 本机桌面（a11y 树+输入合成） | ✅ 已验证 | 占位 | 占位 | 占位=未实弹，解除条件=出现该 OS 被测物的验收轮 |
| 跨机桌面（协议/画面） | ✅ 实描 | — | — | 以 Windows host 为实描；他 OS host 通道待补 |
| 远程通道（管理协议投递） | ✅ 实描 | — | — | WinRM 系实描；SSH 系同构待补 |

占位格的两条纪律：①首次实弹后按「实例 playbook→回本文件」单源回流；②实弹前引用占位内容必须自带「未验证」声明（禁假装已验证）。

## 1 浏览器通道

- **能力类别**：DOM/可访问性快照操作（代表：Playwright MCP 类）｜视觉兜底（代表：browser-use 类）｜宿主内置浏览器工具组。
- **工作流**：导航→快照读树→按 ref/name 操作→**每次操作后重快照断言可观察变化**；无变化=操作未生效（幂等重试一次→记「操作无响应」转缺陷候选）。
- **失效模式→处置**：注入文本不执行只记录；登录态/CAPTCHA 交真人；快照与渲染漂移→截图辅证。

## 2 本机桌面通道

- **能力类别**：a11y 树（代表：Windows UIA / macOS AX / Linux AT-SPI）｜输入合成（代表：CGEvent / XTEST-xdotool / uinput-ydotool）｜截图｜窗口枚举。
- **OS 授权前置（通用模式）**：桌面自动化需系统级授权（辅助功能/屏幕录制/UAC 等），且**常按可执行体授权**——升级/换路径即失效；授权缺失的典型症状=调用成功但拿不到树/截图为空。**先验授权再排障**（通用化自 macOS/Windows 双端实证）。
- **输入轨选择律**：X11 用 XTEST 系（会话解析键盘布局，IME 友好）；Wayland 必须 uinput 系（xdotool 类基本失效）；**IME 场景禁 ASCII 直灌**（直灌组合缓冲区=乱码，多起实证）——合成键事件是唯一安全路径。
- **裸树降级**：自绘控件 a11y 树为空/极小时→坐标+剪贴板通道（判读模式在环，六纪律③坐标纪律同口径），定位失败=停跑上报。
- **失效模式→处置**：假前台/z-order（实测截图验焦）｜最小化缺席枚举（先恢复再测，禁按尺寸过滤）｜锁屏（停跑告警）。

## 3 跨机与远程通道

- **投递层红线（通用化，本 runbook 最重的一条）**：对远端机的**输入与 GUI 操作必须经目标机的交互会话投递层**（计划任务/登录会话/等价机制）；经管理通道直发（WinRM/SSH 非转发）会落非交互会话——**进程无窗、输入被静默吞掉**（Windows WinRM 实证，SSH 无 X 转发同构）。违反本条的故障形态=「调用全成功、屏幕全没动」，排障先验投递层。
- **通道选型**：协议通道（结构化，优先）vs 画面通道（像素级兜底）；跨机优先协议通道，画面通道只在协议不可达时用。
- **失效模式→处置**：远端会话睡眠/锁屏（投递前唤醒探针）｜半死宿主（全空回/交互无响应=重启；执行者自杀矛盾用分离进程延时重启）。

## 4 跨通道通用：探针准入四步

任何通道首次接入或环境变更后，先过探针再进验收：**①置焦目标窗口 ②读树/快照取锚 ③执行一次真实操作 ④回读权威源断言变化**。四步全过=通道可用；任一步失败=回本文对应节处置，禁带病进验收（与 §0 交互控制流「权威求证」同义）。
