# 可用工具集合与选型判据（tool-selection）

**定位**：判据层文件，不是教程。回答一个问题——执行者拿到某个真实入口时，**凭什么判断一个驱动器「够格」支撑 §1 客户端拟人自动化六纪律**。

**边界（可移植铁律的判据面）**：

- 本文件只写**能力要求与陷阱判据**，库中立、运行时任选；具体驱动器（Playwright 脚本、PyAutoGUI 封装、项目自研驱动等）一律归**项目侧 tooling/ 资产**，本技能零实例、零脚本。
- 与 §1 六纪律的关系：六纪律=**行为要求**（必须做到什么），本文件=**驱动器最低能力清单**（什么工具才配来执行）。选型时先查本清单，选了结构性不达标的驱动器=执行期撞墙的根源在选型，不在执行。
- 与生成侧的关系：验收契约治理侧「自主执行优先设计闸」在**生成期**做载体探针（载体不可达 [UI] 点预改判）；本文件供**执行期**选型复核与任务书执行者手册引用，两边不重复。

---

## 1 入口类型 × 最低能力清单

选型第一步=判定入口类型。**辅助树探测先行**：凡桌面客户端，先探 UIA/AX 辅助树，树够厚走辅助树通道；裸树则降级坐标通道（实证：PC QQ Chromium 客户端 UIA 裸树 5 节点，坐标+剪贴板策略成立）。

### 1.1 Web 页面（DOM 通道）

适用：浏览器可达的用户页面（含 Web 化管理页）。

驱动器**必须**全部满足：

| # | 能力 | 支撑要求 |
|---|---|---|
| 1 | 真实事件派发：click / fill（逐键或等效输入）/ select / check / keyboard / scroll | 真实事件操作 |
| 2 | 操作后可观察变化读取：DOM 文本/结构变化、URL/路由变化 | 操作后验证 |
| 3 | 网络事件可读：请求 URL+状态码 | 操作后验证 |
| 4 | 下载事件可捕获（文件名+字节数/哈希） | 操作后验证、传输产物 |
| 5 | prompt/confirm/alert 可真实处理（输入+取消双路径） | 操作后验证 |
| 6 | 判定时截图或 DOM 快照 | 判定时留证 |
| 7 | 独立 context/profile（多 persona 不混会话）、视口可设 ≥1440×900 | 拟真环境 |

缺 2/3/6 任一项 = **结构性不达标**，不得选。

### 1.2 桌面客户端·辅助树通道

适用：UIA（Windows）/AX（macOS）树够厚的原生客户端。

| # | 能力 | 支撑要求 |
|---|---|---|
| 1 | 控件枚举与寻址（不止窗口级，到控件级） | 会话寻址、控件矩阵 |
| 2 | 控件级真实操作（invoke/select/value 写入） | 真实事件操作 |
| 3 | 操作后属性/结构变化读取 | 操作后验证 |
| 4 | 判定时截屏留证 | 判定时留证 |

**裸树判定**：控件级节点稀疏到无法寻址（个位数节点、仅窗口+ pane 壳）即判裸树，**不得**在裸树上硬走辅助树通道点到失联后才发现——降级 1.3。

### 1.3 桌面客户端·坐标+剪贴板通道

适用：无辅助树或裸树的客户端（Chromium 套壳、自绘 UI、游戏类渲染）。

驱动器**必须**全部满足：

| # | 能力 | 支撑要求 | 踏坑实证 |
|---|---|---|---|
| 1 | 窗口枚举**含最小化实例**：按标题枚举，不得按可见性/尺寸过滤 | 窗口枚举纪律 | 最小化后驱动器找不到目标 |
| 2 | 前台/焦点验证：动作前截图确认目标窗口真在前台 | 焦点/上下文自查 | 共享桌面点击撞 Excel；锁屏两次被拦 |
| 3 | 物理分辨率截屏：DPI 感知，截图经工具回读降采样时按物理分辨率换算坐标 | 坐标纪律 | 侧栏收起致按钮位移，首点落空 |
| 4 | 剪贴板读写：粘贴注入（长文/特殊字符/全角）+ 写入后立即使用并回读校验 | 读判通道=剪贴板回读 | 键入被 IME 吞、全角变半角 |
| 5 | 键鼠真实事件派发（SendInput 级，非仅消息模拟） | 真实事件操作 | — |
| 6 | 判定时截屏留证（判定时刻，非事后补） | 判定时留证 | — |
| 7 | 会话寻址：脚本开头搜索/导航到目标会话并验证其标识可见 | 会话寻址纪律 | 审批 suite 发进错误会话，5 条全废 |

缺 2/3/6 任一项 = 结构性不达标。

### 1.4 人工操作（降级终点）

无驱动可用时的合法出口，不是偷懒：记录逐步人工步骤+照片/笔记留痕，execution-log 记能力缺口。**禁止静默退回 API 探测冒充**（API 探测不是任何 [UI] 点的降级形态）。

## 2 选型三问（驱动器评估）

选定驱动器前必答，写入场景日志：

1. **操作后验证可达吗**——该驱动器能否读到至少一种可观察变化（DOM/网络/属性/剪贴板回读）？只能「发动作、看不到结果」的驱动器不合格。
2. **判定时留证可达吗**——判定时刻能否截屏/DOM 快照？事后补证驱动不合格。
3. **六纪律哪条它结构性做不到**——逐条过 §1 六纪律（焦点自查/会话寻址/坐标纪律/窗口枚举/视觉双模式/宿主健康），有做不到的一条 = 不达标，降级或换通道，**禁止硬跑**（硬跑=把可预见的失败留到执行期才发现）。

## 3 已知陷阱速查（库中立表述）

| 陷阱 | 症状 | 处置判据 | 对应纪律 |
|---|---|---|---|
| DPI 缩放坐标漂移 | 逻辑坐标≠物理像素，点击系统性偏移 | 进程声明 DPI 感知；截图降采样一律按物理分辨率换算后再定点 | 坐标纪律 |
| 布局状态变化 | 侧栏开合/窗口尺寸/最小化后旧坐标全部作废 | 坐标只从**当前实测截图**推导；布局一变即重取 | 坐标纪律 |
| IME 吞键/全角变形 | 键入丢字符、全角变半角、快捷键被输入法拦截 | 文本输入一律剪贴板注入（写入→粘贴→回读校验） | 通道选型 |
| 剪贴板竞态 | 共享桌面下操作者/其他进程覆写剪贴板，粘贴出别的东西 | 共享桌面必须预写「清场窗口或独立会话」二选一；写入后立即使用 | 焦点自查 |
| 模板匹配误判 | 主题色/缩放/字体变化致 locate 误命中或永不命中 | 判读模式兜底；模板模式先锚点后操作点，**定位失败=停跑上报**，判断环不许模板闭合 | 视觉双模式 |
| z-order≠真前台 | 窗口在枚举顶部但锁屏/被其他窗口遮挡 | 动作前截图自查前台，异窗/锁屏立即停跑+告警，禁止盲打点 | 焦点自查 |
| 最小化窗口缺席 | 按可见枚举找不到目标窗口 | 枚举不得按尺寸/可见性排除；先恢复再测量 | 窗口枚举纪律 |
| 宿主服务半死 | 全部回合空回/交互类无响应/引擎静默 | 健康检查；分离进程延时重启（避免自杀矛盾）；被测系统自带 AI 可作第一诊断者 | 宿主健康 |
| 配置类编辑致 watcher 回退 | 改了配置不生效且默认覆盖、不自愈 | 配置编辑后验证文件合法性+回读生效值 | 宿主健康 |
| 异步队列冻结 | 长回合后台等待把队列挂死，后续用例全堵 | 队列上限/并发类用例先于任何长回合执行 | 战术三则 |
| 会话级放行缓存 | 一次挂起放行后同类操作不再触发确认 | 用例间显式清障（取消/TTL/文字裁决）并预判缓存影响 | 战术三则 |

## 4 降级链

```
驱动器选型不达标
  → 同通道换驱动器（重答选型三问）
  → 入口降级：辅助树 → 坐标+剪贴板 → 人工操作
  → 人工操作：步骤+照片/笔记留痕
  → 全程禁止：静默退回 API 探测 / fire-and-forget 无验证操作
```

降级必须在 execution-log 记「能力缺口+理由+替代手段」，与自检 #17「有意跳过」同口径；因驱动器不达标降级不豁免 UI 点的证据要求——UI 点无 UI 证据最高仍只记 PARTIAL。
